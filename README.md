# Rollent 인사평가 웹앱 — 인터랙티브 목업

팀원들이 브라우저에서 화면 흐름과 기능 구성을 검토하기 위한 **목업**입니다.
백엔드·데이터베이스·인증 서버와 연결되어 있지 않으며, 모든 데이터는 가상 데이터입니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본값 http://localhost:5173)를 브라우저에서 엽니다.
로그인 화면에서 아무 사번과 비밀번호를 입력하면 들어갈 수 있습니다.
(사번에 `2020001`처럼 가상 사용자의 사번을 넣으면 인사말에 그 사람의 이름이 표시됩니다.)

## 기술 스택

- Vue 3 + Vite
- Vue Router (해시 방식, `#/home` 등)
- Bootstrap 5 (CSS만 사용)
- 차트는 라이브러리 없이 SVG로 직접 그림

## 폴더 구조

```
src/
  store.js            가상 데이터와 점수 계산(reactive 상태 하나)
  router.js           화면 경로, 로그인 확인
  App.vue             사이드바 레이아웃, 확인 팝업, 알림
  components/         사이드바, 모달, CSV 버튼, 차트, 로고
  views/              로그인, HOME, 팀 관리, 사원 관리, 평가항목, 관리자 평가, 응답결과
tests/smoke-test.mjs  브라우저 스모크 테스트
```

## 데이터 동작

- 화면을 이동해도 데이터가 유지됩니다.
- 팀장은 사원 관리의 "역할=팀장 + 소속 팀"으로 정해집니다. 사원 관리에서 새 팀 이름을 입력하면 팀 관리에도 팀이 생깁니다.
- **새로 고침하면 초기 가상 데이터로 돌아갑니다.** 로그인 상태만 탭을 닫기 전까지 유지됩니다.
- 점수는 100점 만점으로 환산합니다. 1~5점은 ×20, Y는 100점, N은 0점입니다. 주관식과 서술형은 점수에 넣지 않습니다.
- 한 평가 유형의 점수 항목(Y/N, 1~5점)에 모두 응답하면 그 유형이 완료됩니다.
  그래서 평가항목을 새로 추가하면 이미 완료된 사람도 다시 '진행 중'이 됩니다.
- 최종 점수 = 자기평가 × 가중치 + 팀장평가 × 가중치 + 임원평가 × 가중치. 세 유형을 모두 마친 사람만 계산합니다.

## 브라우저 테스트

PC에 설치된 Microsoft Edge를 헤드리스로 띄워 주요 화면과 동작 83가지를 확인합니다.

```bash
npm run build
npx vite preview --port 4173      # 터미널 1
npm run test:smoke                # 터미널 2
```
